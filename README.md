# Digitakt Companion for Windows — preview 0.9

A native Windows x64 standalone synth and VST3/CLAP instrument, controlled from
Digitakt MIDI or a DAW. This folder contains the Windows project and its native
C audio engine.

## Run

Close the running Companion, then open `Windows/dist/0.9.0/Digitakt Companion.exe`. The complete 0.9 package is stored beside the running older build.

The eight-track pixel interface contains four independent sound tracks,
two independent modulation curve editors on tracks 5–6, Digitakt I effects/send
controls on track 7, and mixer/recorder track 8. Home uses two rows of four tiles.
Assign Synth, Metallic or FM to tracks 1–4 by
right-clicking a tile or clicking its **...** button. The standalone also supports
VST3/CLAP instruments and two insert effects per sound track with floating editors.

Preview0.9 makes the recorder device-based: detected input/output inventories,
up to64 named mono/stereo input lanes, external-input capture, automatic mono/pair
allocation, explicit input enabling and an optional final Companion mix. Routes
follow physical channel identities instead of shifting with enabled channels.
See `Windows/RECORDING.md` for setup and migration.

Preview 0.8 added odd beat lengths and independent rate multipliers on a common
RATE page, live modulation CC outputs, and track 8's Companion/Digitakt mixer
and multitrack recorder. Select enabled Overbridge ASIO inputs for the eight
hardware tracks and stereo main; the four Companion stems and two modulation
CC lanes record alongside them. See `Windows/RECORDING.md` for setup and limits.

Preview 0.7 added eight stable, individually CC-addressed vertices per curve,
two vertex LFOs per curve, a simple-synth Mono Legato/glide page, and native
retrigger/filter stability corrections. See `Windows/DSP_RETRIGGER_NOTES.md`
for the click investigation and before/after measurements.

Preview 0.6 added fixed, page-independent CC addresses, eight freely assigned
signed routes per curve, modulation CC/channel labels, Companion master clock
and transport, a steadier tempo display, optional stereo input monitoring with
manual timing alignment, configurable hardware display correction and standard
plugin-folder shortcuts. Read `Windows/MIDI_CC_REFERENCE.md` before updating
Digitakt parameter locks: the previous page-following CC assignments are retired.

DAW plugin builds are in `Windows/dist/0.9.0/Plugins/`. Copy the complete VST3 bundle
or the CLAP file to a location scanned by your DAW.

## Build

Install CMake 3.22+, Git and recent Visual Studio C++ Build Tools with a Windows
SDK, then run from this folder:

```powershell
.\Windows\build.ps1
```

The script builds the app and both plugin formats, runs the test suites and
packages the outputs into `Windows/dist/`. Use `-DSPOnly` to build the native
C audio engine and its tests without JUCE.

## Folder layout

- `Audio/`: native C DSP implementation and public header, required by Windows.
- `Windows/Source/`: Windows app, plugin processor, UI, hosting, modulation and MIDI.
- `Windows/Tests/`: DSP, project-state and plugin integration tests.
- `Windows/Patches/`: factory patch.
- `Windows/third_party/`: pinned JUCE and CLAP dependencies with their notices.
- `Windows/build/`: generated build products.
- `Windows/dist/`: ready-to-run executable, DAW plugins and documentation.
- `Windows/previews/`: UI snapshots generated by the integration tests.

See `Windows/README.md` for operation and MIDI setup, `Windows/VALIDATION.md`
for completed checks, and `Windows/THIRD_PARTY.md` for dependency notices.

See `FUTURE_IDEAS.md` for the remaining animated interface ideas and implementation
status, and `Windows/MIDI_CC_REFERENCE.md` for all page control maps.
